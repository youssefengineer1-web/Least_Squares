Least Squares

Finding the closest possible solution when an exact one does not exist.

What is Least Squares?

For a linear system A x = b, an exact solution may not exist because b is not in the column space of A, written Col(A). Least squares finds the vector x* whose output A x* is as close as possible to b.

x* = arg min ‖A x − b‖2

Geometrically, A x* is the orthogonal projection of b onto Col(A). The difference between them is the residual.

Why the Normal Equations Work

Let the residual be

r = b − A x*

At the closest point, the residual is perpendicular to every vector in Col(A). Since the columns of A span this space:

r ⟂ Col(A)   ⟹   ATr = 0
AT(b − A x*) = 0
ATb − ATA x* = 0
ATA x* = ATb

These are the normal equations. Solving them gives the least-squares solution.

Attempting an Exact Solution

Before using least squares, try to solve A x = b directly:

1 1 | 1
2 1 | 2
3 1 | 2
R2 → R2 − 2R1
1 1 | 1
0 −1 | 0
3 1 | 2
R3 → R3 − 3R1
1 1 | 1
0 −1 | 0
0 −2 | −1
R2 → −R2
1 1 | 1
0 1 | 0
0 −2 | −1
R3 → R3 + 2R2
1 1 | 1
0 1 | 0
0 0 | −1

The last row means 0 = −1, which is impossible. The system has no exact solution, so least squares finds the closest solution instead.

First, form the two sides of the normal equations:

ATA = 14 6
6 3
ATb = 11
5

Now apply row operations to the augmented matrix:

14 6 | 11
6 3 | 5
R1 → (1/14)R1
1 3/7 | 11/14
6 3 | 5
R2 → R2 − 6R1
1 3/7 | 11/14
0 3/7 | 2/7
R2 → (7/3)R2
1 3/7 | 11/14
0 1 | 2/3
R1 → R1 − (3/7)R2
1 0 | 1/2
0 1 | 2/3
x* = [ 1/2, 2/3 ]T

Therefore, A x* is the point in Col(A) closest to b.

Application: Student Performance Data

The Data

This application uses the Student Performance dataset. To make the fitted curve and residuals easy to see, the notebook selects the first 100 observations and keeps only two variables:

VariableMeaning
Hours StudiedThe number of hours a student studied. This is the input, x.
Performance IndexThe student's performance score. This is the response, y.

Each blue point in the plots represents one student. The red curve is the least-squares polynomial, and each green dashed segment is a residual: the vertical difference between an observed score and the prediction.

Code Used

The notebook downloads the dataset, selects the two columns, fits a polynomial with least squares, and draws the residuals. The same code was used for the three plots by changing deg to 1, 3, and 9.

import pandas as pd
import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns
from numpy.polynomial import Polynomial
import kagglehub

sns.set_theme(style="ticks")

path = kagglehub.dataset_download(
    "nikhil7280/student-performance-multiple-linear-regression"
)
df = pd.read_csv(path + "/Student_Performance.csv")

# Select 100 observations and the two variables used in the model.
df_plot = df.loc[:99, ["Hours Studied", "Performance Index"]]

# Change this value to 1, 3, or 9 to compare the three models.
deg = 1
p = Polynomial.fit(df_plot["Hours Studied"], df_plot["Performance Index"], deg)

x_curve = np.linspace(0, 12, 1000)
y_curve = p(x_curve)

plt.figure(figsize=(14, 7))
plt.plot(x_curve, y_curve, color="red", zorder=3)
plt.scatter(df_plot["Hours Studied"], df_plot["Performance Index"], zorder=3)

# Draw the residual for every observation.
for hours, performance in df_plot.itertuples(index=False, name=None):
    plt.plot([hours, hours], [p(hours), performance], "g--")

plt.ylim(0, 110)
plt.yticks(np.arange(0, 101, 10))
plt.xlabel("Hours Studied", fontsize=14)
plt.ylabel("Performance", fontsize=14)
plt.title("Least Squares Application", fontsize=18)
plt.show()

The Fitted Curves

Polynomial regression is still a least-squares problem: changing the degree changes the columns of the matrix A, while the least-squares method remains the same.

Overfitting

Overfitting happens when a model is so flexible that it learns the random variation in the observed data instead of the underlying relationship. It can look very accurate for the data used to create it, but make poor predictions for new students.

The degree-1 model captures the overall upward trend with a simple straight line. The degree-3 model bends smoothly and is more flexible. In contrast, the degree-9 curve swings sharply between the observations and behaves unrealistically near the ends of the data range. Those unnecessary oscillations are a visual sign of overfitting.

A smaller sum of squared residuals on the training data does not automatically mean a better model. A useful model should be chosen for how well it predicts unseen data.
